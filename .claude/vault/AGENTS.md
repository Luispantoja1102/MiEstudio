# Reglas del vault

- Este vault es conocimiento del proyecto, no código. Si una nota contradice el código, **manda el código**: deja la contradicción visible, no la corrijas en silencio.
- No muevas ni borres notas. Agrega.
- Sin secretos (claves, tokens, contraseñas) ni datos de clientes reales.
- Enlaces con `[[Barbella/...]]` solo a notas que existan. Fechas en formato ISO (2026-10-24).
- Una nota por tema. Cortas.
